# iOS tests and acceptance

No executable iOS target exists yet, so there are no runnable iOS tests to place here.

Before an iOS target is treated as functional, add unit tests for parsing and local data handling, then simulator and physical-device tests for file imports, settings handoffs, privacy and failure states. Network Extension behavior additionally requires the relevant Apple entitlement and a reviewed distribution configuration.

Do not add placeholder tests or report a passing suite until a real iOS target and test runner exist.
