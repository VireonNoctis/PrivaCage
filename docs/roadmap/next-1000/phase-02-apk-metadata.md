## Batch implementation notes (milestone 321)

The existing bounded DEX scanner now rejects missing/non-file or greater-than-100-MiB APK archives before opening them. It also skips DEX entries whose declared sizes exceed per-entry/total budgets or whose declared uncompressed-to-compressed ratio exceeds 200:1, and reports that skipped coverage rather than returning findings as if the archive were fully scanned. Regression tests cover missing and oversized inputs and a highly compressible DEX entry. This is static string scanning only; it does not parse every ZIP record independently or prove malware/safety. CI and APK/device-level validation remain pending.
